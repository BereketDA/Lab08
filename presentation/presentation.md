# Лабораторная работа № 8
## Поиск файлов. Перенаправление ввода-вывода. Просмотр запущенных процессов

---

### Цель работы
Ознакомление с инструментами поиска файлов и фильтрации текстовых данных. Приобретение практических навыков по управлению процессами.

---

### Потоки ввода-вывода
- **stdin** — стандартный ввод (дескриптор 0)
- **stdout** — стандартный вывод (дескриптор 1)
- **stderr** — стандартный вывод ошибок (дескриптор 2)

---

### Перенаправление
| Оператор | Значение |
|----------|----------|
| `>` | Перезапись файла |
| `>>` | Добавление в файл |
| `\|` | Конвейер (pipe) |
| `2>` | Перенаправление ошибок |

---

### Поиск файлов
- `find ~ -name "c*" -print` — поиск по имени
- `grep ".conf" file.txt` — поиск по содержимому

---

### Управление процессами
- `ps aux` — список процессов
- `gedit &` — запуск в фоне
- `jobs` — список задач
- `kill <PID>` — завершение процесса

---

### Проверка диска
- `df -h` — использование разделов
- `du -a ~` — размер каталогов

---

### Выводы
Изучены инструменты поиска файлов, перенаправления ввода-вывода и управления процессами.
